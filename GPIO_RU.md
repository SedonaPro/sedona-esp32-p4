# GPIO для Sedona / ESP-IDF

В kit `bclimateEsp32` есть компоненты `GpioInput` и `GpioOutput`.
Они доступны в редакторе после загрузки манифестов с контроллера.
Модуль `gpio` добавляет в демо-приложение `/gpio/di1` и `/gpio/do1`.
Оба изначально выключены, номер вывода -1. Номера — GPIO чипа, не контакты разъёма.

Общие слоты: `pin` (int), `enabled` (bool), `pull` (0 без подтяжки,
1 вверх, 2 вниз), `invert` (bool), `fault` (int, только чтение).
`GpioInput.out` — значение входа после инверсии, обновляется один раз за скан.
`GpioOutput.in` — значение из связи; `initial` — начальный логический уровень;
`out` — последнее успешно переданное логическое значение (не измерение напряжения).
При `in=null` выход освобождается и устанавливается fault=-8.
При остановке, отключении или смене pin старый вывод сбрасывается драйвером
ESP-IDF в состояние по умолчанию (выход отключён; возможна слабая подтяжка).
Во время reset/boot уровни определяются аппаратурой и ROM, не Sedona.

В menuconfig → Sedona VM → GPIO pins available to Sedona указывается список
разрешённых выводов через запятую. По умолчанию он пуст. Не включать выводы
памяти, Ethernet, USB/UART, загрузочных перемычек и других устройств платы.
Один вывод может принадлежать только одному компоненту. Настройка выхода
записывает начальный уровень в защёлку перед включением выходного драйвера;
в том же скане затем применяется `in`. Это не задержка начального состояния.

Коды fault: 0 — успешно; -1 — неверный pin/pull; -2 — pin не разрешён;
-3 — занят другим компонентом; -4 — нет настройки/неверный режим;
-5 — ошибка драйвера; -6 — выключен; -7 — GPIO не эмулируется на ПК;
-8 — null на входе выхода. При fault вход возвращает false: потребитель должен
проверять fault отдельно. Встроенной фильтрации дребезга, PWM и прерываний пока нет.

Пример: разрешить два свободных вывода согласно схеме платы, задать входу и
выходу соответствующие pin, включить enabled. Связать `di1.out` → `do1.in`.
Внешние цепи должны соответствовать уровням GPIO платы (не 24 В).

Проверка нативного слоя на инструментированной заглушке драйвера:
`python3 tests/gpio_native_test.py`.
Эта проверка не заменяет измерение уровней/проверку перемычкой на устройстве.
